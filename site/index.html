02 / THE SYSTEM

Quiet on the surface.
Precise underneath.

One local boundary, a small set of focused services, and a provenance contract that stays intact from upload to answer.

01⌕

Index locally

SQLite keeps metadata and extracted fields nearby. Original files stay below a guarded vault root, not in a remote blob.

SQLite · local files · safe paths
02⌖

Cite the field

Answers carry the document, page, field ID, value, and confidence that support them. Missing facts stay missing.

Page · field · confidence
03◌

Show uncertainty

Low-confidence extraction moves to a review queue. People can accept, correct, or dismiss it without losing the original source.

Review · correct · verify

03 / THE BOUNDARY

Private by default,
clear about limits.

KinVault is a local-first demo. No sign-in, paid API, external OCR, analytics, or remote storage is required to explore the real app.
